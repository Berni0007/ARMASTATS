# ARMASTATS

Своя статистика для серверов Arma Reforger.

## Как устроено

```
игровой сервер (мод ZarubaStats)  --POST JSON-->  хост (bot/)  -->  Discord
```

- `mod/` — серверный аддон Reforger. Ловит события (вход, выход, убийства, конец раунда) и шлёт их на хост.
- `bot/` — сервис на Linux-хосте. Принимает события, хранит статистику, держит Discord-бота.
- `docs/` — архитектура и схема событий.

## Состояние

Этап 1: тест связи «мод → хост». Мод при старте игры шлёт `ping`, сервис пишет его в журнал.

## Запуск сервиса

```
cd bot
STATS_TOKEN=свой_секрет PORT=8787 node src/server.js
```

Проверка: `curl http://localhost:8787/health`

## Настройка мода

При первом запуске сервера с модом создаётся файл `profile/ZarubaStats/config.json`.
В нём задаются `apiUrl`, `token` и `serverId`. После правки сервер нужно перезапустить.
